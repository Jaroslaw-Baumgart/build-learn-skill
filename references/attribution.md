# Provenance

Created 2026-10-23 from a project-based mentoring agreement and explicit /mentor and /free decisions. This distributable package contains no participant profile, project roadmap, progress history, personal paths, or application binaries. Each project owns its own learning documents; blank templates are supplied for first-use setup.

Communication guidance is adapted from ideas in [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd), reviewed 2026-10-23. Retained: actionable instructions, bounded steps, visible verified progress, factual error handling, and reconsidering repeated failed remedies. Deliberately not adopted: diagnosis assumptions, mandatory recaps, rigid item/time limits, or rules that suppress needed explanations.

The upstream scripts, model runners, and hooks were not copied or installed. The helper in this package is a separate read-only project-context tool. The upstream MIT notice is retained below for adapted guidance; this is not a claim of clinical validation or guaranteed model compliance.
